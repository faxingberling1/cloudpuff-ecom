# ☁️ CloudPuff Plushies — Dreamy Kawaii E-Commerce Store 🧸✨

> An interactive, joy-first e-commerce web application featuring squish physics, ambient soundscapes, real-time custom plushie building studio, size guides, day/night themes, and official adoption certificates.

**Design & Development by Arsalan Abbas 💖**

---

## ✨ Features

- 🧸 **Adoptable Plushie Catalog**: Full product details, squishiness ratings, personality notes, and bundles.
- 🎨 **Custom Plushie Studio (`/customizer`)**: Real-time workshop to customize fur color, scents (strawberry, lavender, warm vanilla, matcha), accessories, and custom engraved collar tags.
- 📐 **In-Page Real-World Size & Hug Guide**: Interactive 3D/visual comparisons against pillows, laptops, house cats, and coffee mugs with instant height deltas.
- 🌙 **Day & Twilight Night Mode**: Custom dual-palette design system with glassmorphism and contrast optimizations for late-night snuggling.
- 🎵 **Web Audio Soundscapes & Lullaby**: Integrated ambient bedtime lullaby chimes, squish effects, and tactile audio feedback using the Web Audio API.
- 🎮 **Cloud Hop Mini-Game (`/game`)**: HTML5 canvas arcade game where jumping through clouds unlocks secret 25% discount reward coupons.
- 🚚 **Live Cuddle Tracker & Milestones**: Simulated real-time courier radar, milestone stepper, and SMS delivery notifications.
- 📜 **Official Adoption Certificate (`/checkout`)**: Printable post-checkout adoption birth certificates with unique Registry numbers and parental vows.
- 💖 **Interactive Wishlist & Head Pats**: Save favorite plushies and give them virtual head pats.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Vanilla CSS with custom responsive design system tokens
- **Graphics & Audio**: HTML5 Canvas (arcade game) & Web Audio API (sound synthesizer)
- **Icons & Assets**: Custom SVG & curated kawaii assets

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ installed

### Installation

```bash
# Clone the repository
git clone https://github.com/faxingberling1/cloudpuff-ecom.git

# Navigate into project directory
cd cloudpuff-ecom

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the app.
